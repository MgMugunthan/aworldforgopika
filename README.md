# MG × G — Website

A mobile-friendly, standalone website for the MG × G interactive story.

## Run locally
Open `index.html` in a browser. No build tools, server, API keys, or dependencies are required.

## Add your images
Upload the image files listed in `photo_mg/IMAGE_FILES_README.txt` into the `photo_mg/` folder. Keep the folder beside `index.html`.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then Save.
4. Wait for GitHub Pages to publish the website URL.

The website works without images while you prepare them. Once you upload the images to `photo_mg/`, the website loads them automatically from that folder.
